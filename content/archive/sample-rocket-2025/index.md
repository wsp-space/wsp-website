WR-01 は、WSP が初めて設計から打上まで通したハイブリッドロケットです。「機体を壊さずに回収する」ことを最優先にして、到達高度は欲張らずに決めました。

## ミッション

目的は、設計・製作・試験・打上・回収の流れを一度最後まで通すことです。成功の基準を三段階に分けて、打上の前に決めておきました。

| 基準 | 内容 | 結果 |
|---|---|---|
| ミニマム | 正常に点火し、ランチャーを離れる | 達成 |
| フル | パラシュートが開き、機体を回収する | 達成 |
| アドバンスド | 搭載計器で高度と加速度を記録する | 一部達成 |

## 機体諸元

| 項目 | 値 |
|---|---|
| 全長 | 1,650 mm |
| 外径 | 100 mm |
| 打上時質量 | 6.2 kg |
| 推進方式 | ハイブリッド |
| 最大推力 | 約 350 N |
| 燃焼時間 | 約 3.5 秒 |
| 回収方式 | 頂点検知で分離、パラシュート1段 |
| 搭載電装 | 気圧・加速度センサ、GPS、無線テレメトリ |

## 体制

| 班 | 人数 | 担当 |
|---|---|---|
| 構造 | 4人 | 機体筒、ノーズ、フィン、分離機構 |
| 推進 | 4人 | エンジン、地上燃焼試験 |
| 電装・ソフト | 4人 | 搭載計器、点火制御、地上局 |
| 回収・記録 | 2人 | パラシュート、射場の手順書、写真 |

## 経過

| 時期 | 出来事 |
|---|---|
| 2025年4月 | 構想。成功基準と目標高度を決める |
| 2025年7月 | 設計審査。図面と手順書を外部の先輩に見てもらう |
| 2025年10月 | 地上燃焼試験 1回目。点火が遅れ、点火系を作り直す |
| 2025年12月 | 地上燃焼試験 2・3回目。推力と燃焼時間が設計値に入る |
| 2026年2月 | 機体の組立、分離試験、射場リハーサル |
| 2026年3月 | 伊豆大島で打上、回収 |

## 結果

打上は2回目の点火で成功しました。最高到達高度は約 820 m で、頂点の約 1 秒後に分離し、パラシュートで射場の北側に降りました。機体は大きな損傷なく回収できています。

搭載計器は加速度を最後まで記録できましたが、気圧センサは振動で値が飛び、高度は GPS の記録から求めています。

## 振り返り

うまくいったこと:

- 成功基準を先に決めていたので、当日の中止判断で迷わなかった
- 燃焼試験の記録を毎回残していたので、点火系の不具合を短時間で直せた

次の機体に持ち越すこと:

- 気圧センサの防振。基板の固定方法から見直す
- 1回目の点火失敗の原因は、点火器の配線の取り回し。手順書にチェック項目を足す
